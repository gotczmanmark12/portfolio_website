# SiteVibeStudio

Egy egyszerű weboldal kisvállalkozásoknak, akiknek nincs még saját weblapjuk.  
Cél: gyors, modern, reszponzív weboldal készítése 50–100€ áron.

## Fő funkciók
- Bemutatkozó oldal
- Kapcsolati űrlap
- Google Maps integráció (cégek keresésére)
- Mobilbarát design

## Fejlesztés folyamata
- Minden funkció külön commitként
- HTML/CSS/JS folyamatos fejlesztés
- Projekt a GitHub Pages-en is elérhető: [https://gotczmanmark12.github.io/portfolio_website/]

## Technológiák
- HTML5
- CSS3
- JavaScript 
- Git / GitHub
